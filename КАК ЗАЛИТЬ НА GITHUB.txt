ПОКУШЕНИЕ НА ПАПОЧКУ — как выложить игру на GitHub Pages
=========================================================

Что в архиве
------------
index.html        — сама игра (все тексты, коды и настройки внутри, в блоке CONFIG в начале файла)
*.png, *.webp     — персонажи, фоны, фото
*.mp3             — музыка (гонка и перестрелка)
sql-asm.js        — движок SQL для ноутбука в главе 4
gallery/          — ФОТО ДЛЯ ГАЛЕРЕИ В ТЕЛЕФОНЕ МАТВЕЯ
.nojekyll         — служебный пустой файл для GitHub Pages, не удаляй

1. Распаковать
--------------
Windows: правой кнопкой по архиву → «Извлечь всё…» → «Извлечь».
Mac: двойной клик по архиву.
Получится папка pokushenie-na-papochku. Внутри — index.html и остальные файлы.

2. Создать репозиторий
----------------------
1) Зайди на github.com и войди в аккаунт (или зарегистрируйся).
2) Справа сверху «+» → «New repository».
3) Repository name: например  papochka
4) Выбери Public (на бесплатном тарифе GitHub Pages работает только с публичными репозиториями).
5) Нажми «Create repository».

3. Загрузить файлы
------------------
1) На странице нового репозитория нажми ссылку «uploading an existing file»
   (или кнопку «Add file» → «Upload files»).
2) Открой распакованную папку pokushenie-na-papochku, выдели ВСЁ ВНУТРИ неё
   (Ctrl+A на Windows, Cmd+A на Mac) и перетащи в окно браузера.
   Важно: перетаскивай содержимое папки, а не саму папку — index.html должен оказаться в корне репозитория.
   Папка gallery перетащится вместе с фото (в Chrome/Edge/Firefox это работает).
   Файл .nojekyll на Mac скрыт — это не страшно, можно его не загружать.
3) Внизу нажми зелёную кнопку «Commit changes» и дождись окончания загрузки.

4. Включить сайт
----------------
1) В репозитории открой «Settings» (вкладка сверху) → слева «Pages».
2) В разделе «Build and deployment» → Source: «Deploy from a branch».
3) Branch: выбери «main» и папку «/ (root)» → «Save».
4) Подожди 1–3 минуты и обнови страницу — сверху появится ссылка вида
   https://ТВОЙ-ЛОГИН.github.io/papochka/
   Это и есть игра. Её можно открыть на компьютере и на телефоне.

5. Как добавить фото в галерею телефона
---------------------------------------
Фото лежат в папке gallery и должны называться по номерам без пропусков:
  1.jpg, 2.jpg, 3.jpg, 4.jpg, 5.jpg …
Подходят .jpg, .jpeg, .png, .webp. Сейчас там 1.webp–4.webp, новые называй 5.jpg, 6.jpg и т. д.
Если номер пропущен (например, есть 5 и 7, но нет 6), всё после пропуска не покажется.

Добавить на GitHub:
1) В репозитории открой папку gallery.
2) «Add file» → «Upload files» → перетащи фото (уже переименованные) → «Commit changes».
3) Через 1–2 минуты обнови игру — фото появятся в «Галерее».
Совет: большие фото с телефона (5–10 МБ) лучше уменьшить, чтобы галерея грузилась быстро.

6. Как поменять коды перед праздником
-------------------------------------
Открой index.html в репозитории → значок карандаша («Edit this file») → найди (Ctrl+F) и замени значения:
  REAL_WORLD_CHALLENGE_CODE: '1234'   — глава 2, код в телефоне после задания с портретом
  DOSSIER_ACCESS_WORD: 'КОМПАС'        — глава 3, кодовое слово в досье
  TRACE_ACCESS_CODE: '2468'            — глава 4, пароль ноутбука
  armoryPattern: [7, 4, 1, 5, 3, 6, 9] — глава 5, узор «М» на двери оружейной
                                        (точки: 1 2 3 / 4 5 6 / 7 8 9)
  FINAL_DOOR_CODE: '7777'              — глава 7, код двери к Алине
Коды — 4 цифры. Потом «Commit changes», через минуту сайт обновится.

7. Полезно знать
----------------
• Главы открываются по очереди. Чтобы проверить любую главу сразу, добавь в конец ссылки  #all
  (например https://ТВОЙ-ЛОГИН.github.io/papochka/#all). Матвею давай ссылку без #all.
• Прохождение запоминается в браузере. Чтобы начать с нуля — открой ссылку в режиме инкогнито.
• Публичный репозиторий видят все, у кого есть ссылка или кто найдёт его на GitHub:
  фото, коды и ответы лежат в открытом виде. Не давай Матвею ссылку на сам репозиторий — только на сайт.
